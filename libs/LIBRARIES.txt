  ★ NEW: PIXIJS v8
================================================================
  GitHub     : https://github.com/pixijs/pixijs  (57k stars)
  CDN        : https://cdn.jsdelivr.net/npm/pixi.js@8/dist/pixi.min.js
  Version    : 8.x
  Size       : ~1.1 MB (or ~300 KB with slim build)
  Renderer   : WebGL / WebGPU (fastest 2D in browser)

  WHAT IT DOES:
    The fastest 2D renderer in the browser — 5-10× faster than Canvas 2D.
    Has built-in sprite sheets, filters (blur, glow, displacement, color
    matrix), and a full scene graph. Pairs perfectly with GSAP for
    high-performance logo reveals with shader effects.

  KEY FEATURES:
    - DisplacementFilter  — warp/melt/liquid effects using a grayscale map
    - BlurFilter          — fast GPU blur
    - GlowFilter          — neon glow on sprites
    - ColorMatrixFilter   — hue shift, saturation, brightness
    - Graphics API        — draw shapes/lines procedurally
    - Sprite              — display PNG/texture at 60fps

  USAGE EXAMPLES:
    // Basic setup
    const app = new PIXI.Application();
    await app.init({ width:1080, height:1920, backgroundAlpha:0 });
    document.getElementById('stage').appendChild(app.canvas);

    // Load logo PNG as texture
    const texture = await PIXI.Assets.load('aristokrat_logo.png');
    const logo    = new PIXI.Sprite(texture);
    logo.anchor.set(0.5);
    logo.x = 540; logo.y = 960;
    app.stage.addChild(logo);

    // Displacement filter — liquid/warp effect
    const dispTexture = await PIXI.Assets.load('displacement_map.png');
    const dispSprite  = new PIXI.Sprite(dispTexture);
    const dispFilter  = new PIXI.DisplacementFilter(dispSprite);
    dispFilter.scale.set(80); // intensity
    logo.filters = [dispFilter];
    app.stage.addChild(dispSprite);

    // Animate with GSAP — reduce displacement to 0 as logo reveals
    gsap.to(dispFilter.scale, { x:0, y:0, duration:3, ease:'power2.out' });

    // Glow filter
    const glowFilter = new PIXI.filters.GlowFilter({
      distance: 15,
      outerStrength: 2,
      innerStrength: 1,
      color: 0xffd700,
    });
    logo.filters = [glowFilter];

  LOGO REVEAL IDEAS WITH PIXI:
    1. Logo spawns through a liquid displacement warp → displacement fades to 0
    2. Logo glows gold then color-corrects to white
    3. Pixelated blocky logo → blur clears → sharp (use ColorMatrix + Blur)

  BEST FOR: Liquid/warp reveals, glow effects, high-performance 2D WebGL

  ★ NEW: PROTON.JS  (particle engine)
================================================================
  GitHub     : https://github.com/drawcall/Proton
  CDN        : https://cdn.jsdelivr.net/npm/proton-engine/build/proton.min.js
  3D version : https://github.com/drawcall/three.proton  (works with Three.js)
  Size       : ~90 KB

  WHAT IT DOES:
    A dedicated particle system engine with emitters, forces, behaviors,
    and renderers. Much more powerful than manual canvas particles.
    Can render to Canvas 2D or WebGL. Has a Three.js integration for
    3D particles.

  KEY CONCEPTS:
    Proton           — the main engine (update loop)
    Emitter          — emits particles (point, line, sphere zones)
    Particle         — has position, velocity, life, color, radius
    Behaviour        — forces applied to particles:
                       Attraction, Repulsion, Gravity, RandomDrift,
                       Color (fade color over life), Scale (size over life)
    Renderer         — CanvasRenderer | WebGLRenderer | DomRenderer

  USAGE EXAMPLES:
    // Setup
    const proton   = new Proton();
    const emitter  = new Proton.Emitter();
    const renderer = new Proton.CanvasRenderer(canvas);

    // Emit 2000 particles per second for 0.1 seconds (burst)
    emitter.rate = new Proton.Rate(
      new Proton.Span(2000),  // particles per emit
      new Proton.Span(0.1)    // seconds between emits
    );

    // Behaviours
    emitter.addBehaviour(new Proton.Alpha(1, 0));         // fade out
    emitter.addBehaviour(new Proton.Scale(1, 0));         // shrink
    emitter.addBehaviour(new Proton.Color('#fff','#ffd700')); // white→gold
    emitter.addBehaviour(new Proton.RandomDrift(3,3,0.05));
    emitter.addBehaviour(new Proton.Gravity(0.5));

    // Zone — particles start from logo center
    emitter.addInitialize(new Proton.Position(
      new Proton.CircleZone(540, 960, 200) // cx, cy, radius
    ));
    emitter.addInitialize(new Proton.Life(1, 3));
    emitter.addInitialize(new Proton.Velocity(
      new Proton.Span(2,5),
      new Proton.Span(0, 360), 'polar'
    ));

    emitter.emit('once'); // burst
    proton.addEmitter(emitter);
    proton.addRenderer(renderer);

    // Update in RAF loop
    function loop(){ proton.update(); requestAnimationFrame(loop); }
    loop();

    // Logo EXPLODES into particles then reassembles:
    // 1. Start: logo PNG visible
    // 2. Sample logo pixels → store as target positions
    // 3. Emit particles from logo center with outward velocity
    // 4. Add Attraction behavior pointing to target positions
    // 5. Particles spiral out then get pulled back into logo shape

  BEST FOR: Explosion + reassembly reveals, fireworks, logo disintegration


================================================================
  ★ NEW: OGL.JS  (minimal WebGL, shader-first)
================================================================
  GitHub     : https://github.com/oframe/ogl
  CDN (ESM)  : https://cdn.jsdelivr.net/npm/ogl
  Size       : ~8 KB gzipped (zero dependencies)

  WHAT IT DOES:
    Minimal WebGL wrapper — like Three.js but 70× smaller and closer to
    raw WebGL. Designed for developers who want to write their own GLSL
    shaders without Three.js overhead. Perfect for custom shader effects
    on logos — noise dissolve, glitch, scanlines, chromatic aberration.

  KEY CLASSES:
    Renderer   — creates WebGL context
    Camera     — perspective or ortho
    Geometry   — vertex/uv/normal buffers
    Program    — vertex + fragment shader
    Mesh       — geometry + program
    Texture    — load images as GL textures

  USAGE EXAMPLE (noise dissolve reveal):
    <script type="module">
    import { Renderer, Camera, Geometry, Program, Mesh, Texture }
      from 'https://cdn.jsdelivr.net/npm/ogl';

    const renderer = new Renderer({ alpha:true, antialias:true });
    const gl       = renderer.gl;
    document.getElementById('stage').appendChild(gl.canvas);
    renderer.setSize(1080, 1920);

    const camera = new Camera(gl, { fov:35 });
    camera.position.z = 5;

    const geometry = new Geometry(gl, {
      position: { size:2, data: new Float32Array([-1,-1, 3,-1, -1,3]) },
      uv:       { size:2, data: new Float32Array([0,0, 2,0, 0,2]) },
    });

    const program = new Program(gl, {
      vertex: `
        attribute vec2 position;
        attribute vec2 uv;
        varying vec2 vUv;
        void main() {
          vUv = uv;
          gl_Position = vec4(position, 0, 1);
        }
      `,
      fragment: `
        precision highp float;
        uniform sampler2D uTexture;
        uniform float uProgress;  /* 0=hidden, 1=revealed */
        varying vec2 vUv;

        /* Simple pseudo-random noise */
        float rand(vec2 co){
          return fract(sin(dot(co,vec2(12.9898,78.233)))*43758.5453);
        }

        void main() {
          vec4 color = texture2D(uTexture, vUv);
          /* Dissolve: pixel appears when noise < uProgress */
          float noise = rand(vUv * 8.0);
          if(noise > uProgress) discard;
          gl_FragColor = color;
        }
      `,
      uniforms: {
        uTexture:  { value: logoTexture },
        uProgress: { value: 0.0 },       /* GSAP tweens this 0 → 1 */
      },
    });

    const mesh = new Mesh(gl, { geometry, program });
    gsap.to(program.uniforms.uProgress, { value:1, duration:3 });
    </script>

  SHADER EFFECTS YOU CAN BUILD:
    - Noise dissolve (pixels appear one by one via noise threshold)
    - Chromatic aberration (RGB channels offset — glitch look)
    - Scanline / CRT effect (horizontal lines sweep)
    - Radial wipe (circular reveal from center)
    - Fire/plasma background (mathematical fragment shader)

  BEST FOR: Custom GLSL shader reveals, raw GPU effects, lightweight 3D


================================================================
  ★ NEW: CURTAINS.JS  (WebGL shaders on HTML elements)
================================================================
  GitHub     : https://github.com/martinlaxenaire/curtainsjs
  CDN        : https://www.curtainsjs.com/build/curtains.min.js
  Docs       : https://www.curtainsjs.com
  Size       : ~80 KB

  WHAT IT DOES:
    Turns regular HTML img/video/canvas elements into WebGL textured
    planes that you can distort with custom GLSL fragment shaders.
    Great for displacement map reveals — logo appears through a wavy,
    melting, or noisy distortion that clears away.

  KEY CONCEPT:
    HTML element (img tag)  →  curtains converts to WebGL plane
    You write a fragment shader that reads the image texture + a
    displacement texture, offsetting pixel coords to create distortion.
    Animate a uProgress uniform from 1 (max distortion) → 0 (clear).

  USAGE EXAMPLE:
    <div id="canvas"></div>
    <div class="plane">
      <img src="aristokrat_logo.png" data-sampler="uLogoTexture">
      <img src="displacement.png"    data-sampler="uDisplacement" hidden>
    </div>

    <script>
    const curtains = new Curtains({ container: 'canvas' });

    const params = {
      vertexShader: `
        precision mediump float;
        attribute vec3 aVertexPosition;
        attribute vec2 aTextureCoord;
        uniform mat4 uMVMatrix, uPMatrix;
        uniform mat4 uLogoTextureMatrix;
        varying vec2 vLogoUv;
        void main() {
          vLogoUv = (uLogoTextureMatrix * vec4(aTextureCoord, 0, 1)).xy;
          gl_Position = uPMatrix * uMVMatrix * vec4(aVertexPosition, 1);
        }
      `,
      fragmentShader: `
        precision mediump float;
        uniform sampler2D uLogoTexture;
        uniform sampler2D uDisplacement;
        uniform float     uProgress;   /* 1=max warp → 0=clear */
        varying vec2 vLogoUv;
        void main() {
          vec4 disp   = texture2D(uDisplacement, vLogoUv);
          vec2 offset = uProgress * (disp.rg - 0.5) * 0.4;
          gl_FragColor = texture2D(uLogoTexture, vLogoUv + offset);
        }
      `,
      uniforms: {
        progress: { name:'uProgress', type:'1f', value:1.0 }
      }
    };

    const plane = curtains.addPlane(document.querySelector('.plane'), params);
    plane.onReady(() => {
      // GSAP: warp disappears → logo reveals cleanly
      gsap.to(plane.uniforms.progress, { value:0, duration:3, ease:'power2.out' });
    });
    </script>

  BEST FOR: Displacement warp reveals, melting transitions, video distortion

    import { animate, stagger, createTimeline } from
      'https://cdn.jsdelivr.net/npm/animejs@4/lib/anime.min.js';

    // Stagger text chars with spring
    animate('.char', {
      opacity:    [0, 1],
      translateY: [20, 0],
      delay:      stagger(40),
      ease:       'spring(1, 80, 10)',
    });

    // Timeline
    const tl = createTimeline();
    tl.add('.logo',   { scale:[0,1], duration:800, ease:'outElastic(1,0.6)' })
      .add('.tagline',{ opacity:[0,1], duration:500 }, '-=200');

    // Draw SVG path (same as v3)
    animate('.path', {
      strokeDashoffset: [anime.setDashoffset, 0],
      duration: 1200,
      ease: 'inOutSine',
    });
    </script>

  NOTE: v3 (local anime.min.js in libs/) uses old global API.
        v4 (CDN) uses ES module import. They are NOT compatible.
        Use v3 for projects that already use it. Use v4 for new projects.

  BEST FOR: Spring-physics reveals, character stagger, SVG path drawing

  ★ NEW: GLSLCANVAS  (raw GLSL fragment shaders on <canvas>)
================================================================
  GitHub     : https://github.com/patriciogonzalezvivo/glslCanvas
  CDN        : https://cdn.jsdelivr.net/npm/glsl-canvas/dist/umd/index.min.js
  Size       : ~20 KB

  WHAT IT DOES:
    The simplest way to run a GLSL fragment shader in the browser.
    Just add data-fragment attribute to a canvas with your shader code
    (or a URL to a .glsl file). Library handles WebGL context, clock,
    resolution uniforms automatically.

  AUTO-PROVIDED UNIFORMS:
    u_time       — seconds since start (float)
    u_resolution — canvas size in pixels (vec2)
    u_mouse      — mouse position (vec2)
    u_tex0..9    — textures from data-textures attribute

  USAGE EXAMPLE (fire/plasma background):
    <canvas class="glslCanvas" data-fragment="
      #ifdef GL_ES
      precision mediump float;
      #endif
      uniform float u_time;
      uniform vec2  u_resolution;

      float noise(vec2 p){
        return fract(sin(dot(p, vec2(127.1, 311.7))) * 43758.5453);
      }

      void main(){
        vec2 uv = gl_FragCoord.xy / u_resolution;
        float n = noise(uv * 5.0 + u_time * 0.3);
        vec3 col = mix(vec3(0.0,0.02,0.08), vec3(0.9,0.7,0.1), n);
        gl_FragColor = vec4(col, 1.0);
      }
    " width="1080" height="1920"></canvas>
    <script src="glslCanvas.min.js"></script>

  USAGE WITH LOGO TEXTURE (dissolve reveal):
    <canvas class="glslCanvas"
      data-fragment-url="dissolve.glsl"
      data-textures="aristokrat_logo.png"
      width="1080" height="1920">
    </canvas>

    // In dissolve.glsl:
    uniform sampler2D u_tex0;
    uniform float u_time;
    void main(){
      vec2 uv = gl_FragCoord.xy / u_resolution;
      vec4 logo = texture2D(u_tex0, uv);
      float noise = fract(sin(dot(uv*20.0, vec2(12.98,78.23)))*43758.5);
      float reveal = smoothstep(noise, noise+0.1, u_time * 0.2);
      gl_FragColor = logo * reveal;
    }

  BEST FOR: Fire/plasma backgrounds, noise dissolve reveals, GPU effects

  ★ NEW: MOTION CANVAS  (code → export video file)
================================================================
  GitHub     : https://github.com/motion-canvas/motion-canvas  (★ Key tool)
  Website    : http://www.motioncanvas.io/
  Type       : Node.js dev tool (not a browser CDN lib)

  WHAT IT DOES:
    Write animations in TypeScript → they render and export directly as
    MP4 or WebM via FFmpeg. No screen recording. No OBS. Perfect quality.
    Like After Effects but entirely in code.

  HOW IT WORKS:
    1. npm create motion-canvas@latest my-animation
    2. Write your animation in TypeScript (similar to GSAP syntax)
    3. Preview in browser at localhost:9000
    4. Press "Export" → generates PNG sequence or MP4

  BASIC ANIMATION EXAMPLE:
    import {makeScene2D, Img, waitFor} from '@motion-canvas/2d';
    import {createRef, tween, easeInOutCubic} from '@motion-canvas/core';

    export default makeScene2D(function*(view) {
      const logo = createRef<Img>();
      view.add(<Img ref={logo} src="/aristokrat_logo.png" opacity={0} />);

      // Fade in
      yield* tween(1.0, v => logo().opacity(easeInOutCubic(v)));
      yield* waitFor(2);

      // Scale up
      yield* tween(0.8, v => logo().scale(1 + easeInOutCubic(v) * 0.2));
    });

  SETUP:
    npm create motion-canvas@latest
    cd my-animation
    npm install
    npm run dev   # opens preview at localhost:9000

  NOTE: Requires Node.js. Not a browser script. Separate from the
        existing HTML-based animation workflow. But output video can
        be used anywhere — OBS, Premiere, DaVinci Resolve, etc.

  BEST FOR: When you need an actual MP4 file without screen recording


================================================================
  GSAP (Green Sock Animation Platform)
================================================================
  File        : gsap.min.js  (in libs/)
  CDN         : https://cdnjs.cloudflare.com/ajax/libs/gsap/3.12.5/gsap.min.js
  Version     : 3.12.5  (now 100% free as of April 2025)
  Size        : ~71 KB

  WHAT IT DOES:
    Industry-standard JS animation library. Animates any CSS property,
    SVG attribute, DOM element, or JS object with a clean timeline API.
    Used as the master timeline controller in ALL project versions.

  KEY FEATURES:
    - gsap.to() / gsap.from() / gsap.fromTo()
    - gsap.timeline() — sequence multiple animations
    - Easing: power1-4, back, bounce, elastic, sine, expo, circ
    - Staggers: animate multiple targets with delay between each
    - Can tween any JS object property (used for Three.js uniforms)

  USAGE EXAMPLES:
    // Fade in + move up
    gsap.from('.logo', { opacity:0, y:40, duration:1, ease:'power3.out' });

    // Timeline sequence
    const tl = gsap.timeline();
    tl.to('.line',  { scaleX:1, duration:0.8 })
      .to('.logo',  { opacity:1, scale:1, duration:1.2 }, '-=0.3')
      .to('.text',  { opacity:1, y:0, duration:0.6 }, '-=0.2');

    // Stagger multiple elements
    gsap.to('.char', { opacity:1, y:0, stagger:0.05, duration:0.4 });

    // Tween a plain object (for Three.js / custom progress)
    const prog = { p:0 };
    gsap.to(prog, { p:1, duration:5, onUpdate(){ /* use prog.p */ } });

    // Infinite loop
    gsap.to('.glow', { opacity:0.3, duration:2, repeat:-1, yoyo:true });

  BEST FOR: Master timelines, complex sequences, logo reveals
